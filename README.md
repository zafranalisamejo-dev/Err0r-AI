# Err0r-AI Pro · Black-Dragon

## What's new in this build
- **Black + Red hacker theme** (Black-Dragon vibe)
- **Camera** opens live preview with **Zoom In / Zoom Out** (1x – 3x)
- Capture photo → auto attaches → AI (vision model) analyzes it properly
- **Photo / Gallery** opens phone gallery / Google Photos / file picker (NOT camera)
- **Camera button** = only live camera · **Photo button** = saved photos only
- **History click** → scrolls chat to that message + red highlight
- **Read (🔊)** fixed: reliable Start / Stop (no more glitchy pause/resume)
- Double-click Read also forces full stop + clean reset
- **Enter to send** · **Shift+Enter** = new line
- **Paste image** (Ctrl+V) · **Drag & drop** files/photos onto chat
- **Friendly errors** only (no API/JSON dump for users)
- **Toast** notifications instead of browser alerts
- **Escape** closes camera / plugins / sidebar
- **Offline detection** + toast when internet drops / returns
- **New Chat** asks confirmation before clearing
- Better **markdown** (headers, lists, bold, links, safe code blocks)
- AI can describe photos, read text/errors in screenshots, and guide next steps
- Files still work (txt, code, etc.)
- Header + footer clearly show **by Black-Dragon** with clickable link
- When user asks "who made you" or about Black-Dragon → AI tells them to **click Black-Dragon at the top**
- Status pill & badge = Black-Dragon
- Model: `qwen/qwen3.8-27b` (vision + text on Groq)
- Messages: User right, AI left + WhatsApp-style typing

## Run
1. Open `index.html` in browser (HTTPS or localhost recommended for camera)
2. Allow camera permission when asked
3. On Android: Camera button = live camera, Photo button = gallery / Google Photos

Educational / ethical lab use only.
